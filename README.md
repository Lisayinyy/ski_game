# ALPINE RUSH

Single-file Three.js snowboarding prototype. Open `index.html` through a local static server.

## Scenic direction

The exterior is an original procedural environment, informed by the broad visual qualities visible on the [Ikon Pass destinations page](https://www.ikonpass.com/en/destinations): high alpine bowls, distant snow-capped ridgelines, dense conifer tree lines, broad groomed pistes, lift infrastructure, trail markers, and small mountain huts.

No Ikon Pass photography or branding is included in the game. The visual reference is translated into original low-poly geometry and shaders so the game remains self-contained.
